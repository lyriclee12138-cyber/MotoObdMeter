电源电路

顺序：保险在最前（保护整段线）→ 防反接二极管 → TVS 与模块并联。TVS 放在二极管之后是有意的：反接时二极管已经把电流挡住，TVS 不会承受反向电压，也就不会靠烧保险来保护。但它仍然在保险的保护区里。

接线顺序（不用烙铁）

  1. ACC 取电点焊/压好一根线，串上带线保险丝座（1A）。
  2. 保险出线 → 1N5822 阳极；二极管阴极 → 模块 VIN+ 螺丝端子。
  3. 车身搭铁 → 模块 VIN− 螺丝端子。
  4. TVS 两根引脚分别塞进 VIN+ / VIN−，和上面的线共用同一个螺丝。
  5. 模块 USB-A ── USB 线 ──> 开发板 COM 口。
  6. 开发板 3V3/GND/GPIO4/GPIO5 → 收发器（4 根杜邦线）。
  7. 收发器 CANH/CANL 双绞后 → OBD 6 / 14；收发器 GND → OBD 5。

接线帽（Wago 221）只在第 2 步的“保险出线 ↔ 二极管”那一处用得上；其余全是螺丝端子或杜邦线。

量什么正常值不对说明

模块 5V 对 GND5.0~5.3V0V = 保险烧了 / 二极管接反
钥匙 OFF 时模块 5V0V不是 0V = 取的不是 ACC
开发板串口=== Fiddle5 OBD sender ===无输出 = 供电或板子问题

几个必须注意的点

ACC 特有的

  • 起动瞬间电压会掉到 9~10V。模块输入下限是 9V，可能瞬间重启。 不影响使用（车一发动就恢复），但别在打火那一瞬间判断“设备坏了”。
  • 一定要取“开关后”的 ACC，别取到常电。判断方法：钥匙 OFF 时量应为 0V。
  • 保险放在取电点附近，不要放在模块旁边——否则中间这段线短路时没有保护。

接地

  • 电源地接车身搭铁，接地点要打磨露出金属，拧紧后抹点防锈。
  • OBD 5 脚（信号地）接到同一个接地点，别另找地方——两点接地会形成环路，容易引噪声。

走线与防水

  • CANH/CANL 双绞、长度 <30cm、远离降压模块的电感。
  • 整套装防水盒，插头朝下；线束用扎带固定，别只靠插拔力。
  • 模块和开发板之间那根 USB 线要固定，长期震动容易松。
