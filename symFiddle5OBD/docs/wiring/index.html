电源电路

顺序：保险 → TVS → 防反接二极管 → 模块。TVS 接在二极管之前，这点不能反 —— 打火尖峰必须在进入二极管前被削掉，否则几十伏直接压在二极管上，它 40V 的反向耐压扛不住。反接也不用担心：P6KE18CA 是双向的，击穿电压 18V，12V 反接达不到，它不导通，电流由二极管挡住。

接线顺序（不用烙铁）

  1. ACC 取电点焊/压好一根线，串上带线保险丝座（1A）。
  2. 保险出线 → 分两路：一路到 1N5822 阳极，一路到 TVS 引脚 1。这两根是同一个点 —— 用一颗 Wago 三孔把「保险出线 + 二极管阳极线 + TVS 引脚」拧在一起。
  3. 1N5822 阴极 → 模块 VIN+ 螺丝端子。
  4. OBD 4 脚（车身地）→ 模块 VIN− 螺丝端子；TVS 引脚 2 也接到这里（同一个端子或同一个 Wago）。
  5. 模块 USB-A ── USB 线 ──> 开发板 COM 口。
  6. 开发板 3V3/GND/GPIO4/GPIO5 → 收发器（4 根杜邦线）。
  7. 收发器 CANH/CANL 双绞后 → OBD 6 / 14；收发器 GND → OBD 5。

接线帽（Wago 221）用在第 2 步：保险出线、二极管阳极线、TVS 引脚 1，三根拧在一起。其余全是螺丝端子或杜邦线。

几个必须注意的点

ACC 特有的

  • 起动瞬间电压会掉到 9~10V。模块输入下限是 9V，可能瞬间重启。 不影响使用（车一发动就恢复），但别在打火那一瞬间判断“设备坏了”。
  • 一定要取“开关后”的 ACC，别取到常电。判断方法：钥匙 OFF 时量应为 0V。
  • 保险放在取电点附近，不要放在模块旁边——否则中间这段线短路时没有保护。

接地

  • 电源地接 OBD 4 脚最省事 —— 它直通车架，是插头里现成的一根粗针，不用趴下去找螺栓打磨。要接车身搭铁也行，但接地点必须打磨露出金属、拧紧、抹防锈。
  • OBD 5 脚（信号地）也接到同一个点，别另找地方——两点接地会形成环路，容易引噪声。
  • 两个地在哪里汇合：都拉到模块 VIN− 那一颗螺丝上，在那儿汇成一点。不要在 OBD 插头内部把 4、5 短接，也不要让它们各自找地方接地。
  • 只接 5 脚行不行：能亮能跑，但 5 脚是给 ECU 做参考的细线，电源电流从它身上过会抬高信号地电位，CAN 容易偶发坏帧。既然插头里有 4 脚，就用 4 脚。

走线与防水

  • CANH/CANL 双绞、长度 <30cm、远离降压模块的电感。
  • 整套装防水盒，插头朝下；线束用扎带固定，别只靠插拔力。
  • 模块和开发板之间那根 USB 线要固定，长期震动容易松。

三个阶段

① 现在 · 充电宝 已用

充电宝 → USB-C 插开发板 COM 口（不是另一个 USB 口）。一根线同时给电和串口。

  • 用直角 USB-C 线，减少插头受力
  • 充电宝别选"轻载自动关机"的：我们只有 0.2A，有的便宜货会误判空载断电
  • 症状：骑一会儿灯灭 / 屏上显示"发送端未连接"

② 装车 · OBD 取常电 推荐先这样

OBD 16 脚（常电）→ 保险 → 降压模块 → 开发板。不破线，30 分钟能装完。

③ 加强 · ACC 只做使能

如果经常把车停放一两周：在②上串一个继电器，用 ACC 控制通断。熄火后整机彻底断电，静态电流 0。

OBD 取电 vs ACC 取电

A. 从 OBD 16 脚取常电

怎么做：现有那根白色 16 针公头，把 16 脚（常电） 和 4 脚（地） 挑出来， 16 脚 → 保险 1A → 模块 IN+，4 脚 → 模块 IN−，输出 5V 给板子。CAN 也从这个插头出。

优点

  • 不改原车线束，保修期内最容易解释
  • OBD 座自带 7.5~10A 保险，天然多一层保护
  • 电源和 CAN 同一个插头，共地天然，只走一根线
  • 要回滚就拔插头

缺点

  • 16 脚是常电，靠固件深睡兜底，长期停放会耗电瓶
  • 插头长期插着会松动/氧化，震动大 → 必须扎带固定
  • 插着它就插不了诊断仪（要用诊断时拔掉，或买一分二）
  • 有的车型 16 脚受 ECU 控制，熄火其实没电 → 装车前量一下

B. 从 ACC 取电

三种做法（推荐度从高到低）

B1 保险盒取电器（不破线）
按车上保险片尺寸买 fuse tap，插在 ACC／点烟器／喇叭 的保险位，会多出一根正极线；负极就近搭铁。

B2 并接尾灯/牌照灯正极（破线）
刺破夹或剥皮焊接 + 热缩。震动下虚接高发，不推荐。

B3 ACC 只做信号，大电流仍走 OBD 常电（最稳）

OBD 16 ──保险──┬─────────────────> 降压 IN+
               └─ 继电器触点 30→87 ─┘

ACC ──1kΩ──> 继电器线圈 85
车身地 ─────> 继电器线圈 86

ACC 只驱动线圈（几十 mA），不给细线加负载；熄火继电器断开，整机断电。

优点

  • 熄火即断电，完全不耗电瓶（最大价值）
  • 不用操心"停放两周打不着火"

缺点

  • 要找 ACC，不同车型位置不一样
  • 起动瞬间电压跌到 9~10V，降压模块可能重启
  • 破线/加件影响保修（B1 影响最小）
  • ACC 线细，不能直接带负载（所以才要 B3 的继电器）

为什么电源地和信号地要分开：0.2A 的电流在地线上会产生压降，抬高了 CAN 的共模电压，接收裕量变小。只在插头处汇合就没有这个问题。

那些元件到底是干什么的

车上 12V 一点都不干净：发电机调压、起动机通断、点火线圈、继电器断开，都会甩出几百伏、几微秒的尖峰。下面四件套就是为这个准备的，顺序不能换。

保险丝 · 1A 防火灾

干什么：线束一旦短路（磨破皮、进水），电流会瞬间到几十安，把线烧红甚至起火。保险丝在几十毫秒内熔断，牺牲自己保车。

不装会怎样：短路时没东西拦着，最坏是烧线束。这是唯一一个"涉及安全"的元件，不能省。

怎么选：负载 0.2A，选 1A。如果后面接了大电容，用慢熔（T）的，否则开机充电瞬间可能误熔断。

TVS · P6KE18CA 防打火尖峰

干什么：平时它像不存在（高阻，不导通）。只要电压超过约 18V，它瞬间变成导体，把尖峰的能量泄放到地，把电压钳在 ~29V 以内。

不装会怎样：降压模块输入端的 MOS 耐压通常 30~40V，一次打火脉冲就能打穿 → 模块"突然没输出了"，严重时内部短路、烧保险。这种故障没有征兆，很难查。

怎么选：P6KE18CA。18V 关断电压高于充电时的 14.5V（不会误动作），钳位 29V 低于模块耐压。买的是双向（P6KE18CA），两根引脚不分正负，随便插。

肖特基二极管 · 1N5822 防接反

干什么：只让电流单向通过。串在正极上，接反时它截止，后端一点电都拿不到，也就不会炸。

为什么用"肖特基"而不是普通二极管：压降只有 0.3~0.5V（普通硅管 0.7~1V）。我们 0.2A × 0.4V = 0.08W，可以忽略；如果用普通管，压降大、发热多，12V 跌到 11.5V 再进模块也更吃亏。

不装会怎样：接线时手一抖把正负极接反，模块和开发板一起报废。装车改线时这很常见。

大电流场合（几安培）会用 P-MOS 理想二极管，压降 0.02V，但这里没必要。

电解电容 1000µF 储能 · 防重启

干什么：储能。ESP-NOW 发射瞬间，电流会从 0.2A 跳到 0.5A，持续几十~几百微秒。而电线本身有电感（大约 1µH/米），电流不能突变，这几微秒里模块来不及供上，电压就会瞬间塌陷。

不装会怎样：电压塌陷到 ESP32 的复位阈值以下 → 莫名其妙重启。现象是"骑一会儿重启一次""数传着数着断了"，看起来像固件 bug，其实全是电的问题。线越长越容易犯。

关键：装在负载端（开发板旁边），不是装在模块输出端。要抵消的是"线"的电感，离负载越近越有效。

瓷片电容 0.1µF 滤高频

干什么：旁路高频噪声。降压模块内部以几百 kHz 开关，会产生几十 MHz 的振铃；电解电容因为自身等效电感（ESR/ESL），对这么快的信号"反应不过来"，所以并一颗小瓷片专门吃高频。

不装会怎样：开关噪声会顺着电源线跑进 ESP32 和 CAN 收发器。CAN 对噪声更敏感，可能表现为偶发坏帧、丢包——同样很难查。

怎么接：和电解并联，越靠近芯片引脚越好（几毫米）。

更省事的两种做法

A. 买“带保护”的模块
有标注「防反接 / 防浪涌 / 带保险」的车载降压模块，买这种就只剩串一个保险。 买前看清详情页有没有真的写 TVS 和反接保护——很多只写“过流保护”，那是芯片自带的。

B. 成品 USB 输出模块 + USB 线接开发板
如果模块自带 USB-A 输出（比如欣薇这块），一根 USB-A 转 USB-C 线插开发板 COM 口， 连开发板都不用接线，只剩「12V 进模块」两颗螺丝要拧。

三点提醒

  • 5.2V 没问题。开发板 LDO 吃得下，USB 规范也允许到 5.25V。
  • 静态电流要量。这类模块带 USB 识别芯片，空载可能吃 5~20mA。 我们深睡本来只有 15~20mA，模块再吃 15mA 就翻倍了。 量法：12V 输入串万用表 mA 档，不接负载。偏大就把取电点改成 ACC。
  • 快充芯片不会乱升压。它只对支持 QC 的设备协商 9V/12V，ESP32 不会发起协商，输出一直是 5V。

风险清单

保修 破线（B2）可能影响保修，B1 / OBD 取电影响最小。
安全 所有正极必须过保险；接头必须绝缘；远离排气管和运动件。
防水 座桶雨天会进水汽，电子件装防水盒，插头朝下。
震动 插头、端子必须有机械固定，不能只靠插拔力。
调试 所有接线在熄火状态完成，上电前用万用表确认没有短路。
