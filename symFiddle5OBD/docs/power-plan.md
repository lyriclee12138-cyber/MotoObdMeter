# 装车供电方案（v0.1-alpha 之后）

> 手机上看这个：`docs/power/index.html`（同一份内容的网页版，带接线图）

> 面向：SYM Fiddle 5 踏板，车上 12V 系统，OBD 为**标准 16 针**（4/5 地、16 常电、6/14 CAN）。
> 现在：充电宝 + USB-C 供电。目标：做成"插上就一直能用"的车载件。

---

## 0. 结论先看

| 阶段 | 方案 | 一句话理由 |
|---|---|---|
| **现在（台架/初测）** | 充电宝插开发板 **COM 口** | 一根线同时给电和串口，零改动 |
| **装车（推荐）** | **OBD 16 脚取常电 → 12V 转 5V → 开发板** | 不用破线、不用找 ACC，固件已有深度睡眠 |
| **装车（加强版）** | OBD 常电 + **ACC 只做使能**（继电器/MOS） | 停放超过一周也不怕耗电瓶 |

**不要做的事**：把 12V 直接怼进开发板 5V 脚（瞬间烧）；从 OBD 取电不经过保险和 TVS（一次打火脉冲就可能带走模块）。

---

## 1. 先算清楚要多少电

| 部件 | 典型电流 | 峰值 |
|---|---|---|
| ESP32-S3（ESP-NOW 常连，20Hz 上行） | 90~120 mA @3.3V | ~350 mA |
| SN65HVD230 收发器（高速模式） | 10 mA | 17 mA |
| 开发板本身（LDO 静态 + 电源灯 + CH340） | 6~10 mA | — |
| WS2812（30% 亮度） | 15 mA | 20 mA |
| **合计（5V 侧）** | **≈ 0.15~0.20 A** | **≈ 0.5 A** |

> 也就是说：**5V / 1A 就够用，选 2~3A 是为了余量和发热**。

### 深度睡眠时的静态耗电（这才是关键）

发送端固件**已经实现**：总线静默 60 秒 → 深度睡眠，每 5 分钟定时唤醒探一次总线。

| 项 | 电流 |
|---|---|
| 开发板 LDO 静态 + 电源灯 + CH340 | 6~10 mA |
| SN65HVD230（**仍处高速模式**） | ~10 mA |
| ESP32-S3 深睡 | ~0.01 mA |
| 定时唤醒摊薄（5 分钟醒 3 秒） | ~1 mA |
| **合计** | **≈ 15~20 mA** |

换算成电瓶：

```
0.018 A × 24 h ≈ 0.43 Ah/天
踏板车电瓶 6~8 Ah  →  每天约 6% 的容量
```

- **每周都骑**：完全没问题，车一发动就补回来了；
- **停放一两周**：会掉到 40~50%，冬天可能就打不着了；
- **长期停放**：加 ACC 使能，或者干脆把 OBD 插头拔了。

> 想把这 0.43 Ah/天再压一半，最有效的一步是**把收发器打进待机**（Rs 引脚拉高，
> 10mA → 几百 µA），顺带把开发板那颗电源灯去掉。这是后面固件+一根杜邦线的事。

## 2. 阶段一：充电宝（现在就这样用）

```
充电宝 ──USB-C──> 开发板 COM 口（不是 USB 口）
                    ├── 3V3 ──> SN65HVD230 VCC
                    ├── GND ──> SN65HVD230 GND
                    ├── GPIO4 ─> 模块 TX
                    └── GPIO5 ─> 模块 RX
```

要点：

1. **插 COM 口**（板载 USB 转串口那个）。插另一个"USB"口也能跑，但看日志要特殊处理，容易误判成板子死了。
2. 用**直角 USB-C 线**，减少插头受力；线长 0.3~0.5m 足够。
3. 充电宝选**没有"轻载自动关机"**的（很多充电宝低于 50~100mA 会断电；我们 0.2A 一般没事，但便宜货有的 100mA 就判空载）。
   - 症状：骑一会儿灯灭了 / 屏上显示"发送端未连接"。
   - 排查：串个 USB 电流表看电流，或者换一个充电宝。
4. 装车测试时用**防水袋 + 魔术贴**固定在座桶里，别让它滚。

## 3. 阶段二：从车上取电

### 3.1 车上能拿到哪几种电

| 取电点 | 电压 | 什么时候有电 | 备注 |
|---|---|---|---|
| OBD 16 脚 | 12V（充电时 13.5~14.5V） | **常电**（熄火也有） | 原车已有保险（通常 7.5~10A） |
| OBD 4 脚 | 0V（车身地） | — | 电源回路用这个 |
| OBD 5 脚 | 0V（信号地） | — | CAN 参考地用这个 |
| ACC | 12V | 钥匙 ON | 需要在保险盒或线束里找 |

### 3.2 方案 A：OBD 16 脚取常电（推荐先用这个）

**怎么做**（不用破线）：

1. 现有那根白色 16 针公头带尾线，把 **16 脚（常电，一般是红线）** 和 **4 脚（地，黑线）** 挑出来；
2. 16 脚 → 保险丝座（1A）→ 降压模块 IN+；
3. 4 脚 → 降压模块 IN−；
4. 降压模块 OUT 5V → 开发板；
5. 插头插回车上 OBD 座，扎带固定，插头朝下防积水。

**优点**

- **零破坏**：不改原车线束，不碰 ACC，保修期内最容易解释；
- **OBD 座本身带保险**，16 脚那一路通常是 7.5~10A，天然多一层保护；
- **CAN 和电源从同一个插头出**，共地天然，布一根线就够；
- **随插随用**，要拔就拔，回滚成本为零。

**缺点**

- **16 脚是常电**：靠固件的深度睡眠兜底（15~20mA），长期停放仍会耗电瓶；
- OBD 插头长期插着会**松动/氧化**，尤其踏板车座桶里震动大 → 必须扎带固定；
- 插着 OBD 就不能插诊断仪了（要用诊断时拔掉，或买一根一分二）；
- 部分车型的 16 脚受 ECU 控制，熄火后其实没电 → **装车前先量一下**。

### 3.3 方案 B：ACC 取电

**三种做法，从"最推荐"到"最不建议"：**

**B1. 保险盒取电器（fuse tap）** —— 不破线

1. 打开保险盒（踏板车一般在座桶内或前储物格后），找到标 **ACC / 点烟器 / 喇叭 / 转向灯** 的保险位；
2. 用**保险盒取电器**（按车上保险片的尺寸买：mini / 小号 / 微型）插进去，会多出一根正极线；
3. 负极就近找一个车身螺丝搭铁（或从 OBD 4 脚取）；
4. 正极 → 保险（1A）→ 降压模块。

**B2. 并接 ACC 负载线** —— 破线

找尾灯 / 牌照灯 / 仪表 的正极线，用**刺破夹**或剥皮焊接 + 热缩。缺点是破坏原线束，震动下是虚接高发点。

**B3. ACC 只做"信号"，大电流仍走 OBD 常电** —— 最稳，多一个件

```
OBD 16 ──保险──┬───────────────> 降压 IN+
               │
ACC ──1kΩ──> 继电器线圈(85)      继电器触点(30→87) 串在上面那条线上
车身地 ─────> 线圈(86)
```

- ACC 只驱动继电器线圈（几十 mA），**不给 ACC 线增加负载**；
- 熄火 → 继电器断开 → 整机彻底断电 → 静态电流 0；
- 代价：多一个继电器（¥10~15），多一个故障点。

**优点**

- 熄火即断电，**不耗电瓶**（这是最大的价值）；
- 不用担心"停车两周打不着火"。

**缺点**

- 要**找 ACC**，不同车型位置不一样，踏板车有的在车头、有的在座桶保险盒；
- **起动瞬间电压会跌**（踏板车起动机拉低到 9~10V），降压模块输入欠压会重启 → 最好让设备在起动时不工作，或选带欠压不重启的模块；
- 破线/加件会**影响保修**（B1 影响最小）；
- ACC 线通常很细，**不能直接带负载**（所以 B3 才用继电器）。

### 3.4 两者对比

| | OBD 常电 | ACC 取电 |
|---|---|---|
| 改动量 | 极小（只用现有插头的两根线） | 中（找 ACC、加取电器/继电器） |
| 破线 | 不用 | B1 不用 / B2 要破 |
| 熄火后耗电 | 15~20 mA（靠固件睡觉） | 0 |
| 长期停放 | 掉电瓶（约 6%/天） | 无影响 |
| 起动压降 | 不影响（设备本来在睡） | 可能重启，需要处理 |
| 保修 | 基本无影响 | B1 影响小，B2 明显 |
| 回滚 | 拔插头 | 拆线 |
| 适合 | **每周都骑** | **经常停放** |

**我的建议**：先做 OBD 常电（30 分钟能装完、不用破线），骑一两周看电瓶状态；
如果发现停放几天后启动无力，再加 ACC 使能（B3），而不是拆掉重来。

### 3.5 完整拓扑（推荐版）

```
                    ┌──────────── 保险 1A ────────────┐
OBD 16 (常电) ──────┤                                 │
                    └── TVS(SMBJ18A) ──┐              │
                                        │              │
OBD 4  (车身地) ────────────────────────┴── 降压模块 IN−
                                        │
                                   [12V→5V 3A]
                                        │
                          OUT+ 5V ──┬── 1000µF/16V ──┬── 开发板 5V
                                    │                 │
                          OUT− GND ─┴── 0.1µF ────────┴── 开发板 GND

OBD 6  (CAN-H) ──┐
                 ├── 双绞，<30cm ──> SN65HVD230 CANH/CANL
OBD 14 (CAN-L) ──┘

OBD 5  (信号地) ──> SN65HVD230 GND（与电源地只在 OBD 插头处汇合）
```

## 4. 保护电路：四件套，缺一不可

| 位置 | 元件 | 作用 | 参数 |
|---|---|---|---|
| 最前 | **保险丝** | 线束短路时不烧车 | 1A 快熔（有 1000µF 电容时用 1A 慢熔/T） |
| 保险后 | **TVS** | 吸收打火/负载突降的尖峰 | SMBJ18A（18V 关断，钳位 ~29V） |
| TVS 后 | **防反接** | 接反了不炸模块 | SS34 肖特基（压降 0.4V）或 P-MOS 理想二极管 |
| 输出 | **电容** | 吸收 ESP-NOW 突发电流 | 1000µF/16V 电解 + 0.1µF 陶瓷 |

其他：

- **线径**：0.2A 用 22AWG 足够，选 22AWG 主要是为了机械强度；
- **接地**：电源回路走 4 脚，CAN 参考地走 5 脚，**两者只在 OBD 插头处汇合**
  （避免 0.2A 在地线上产生压降，抬高 CAN 共模）；
- **CAN 线**：CANH/CANL 必须**双绞**，长度 <30cm，远离降压模块的电感/开关节点；
- **5V 怎么进开发板**：
  - 走 USB-C：方便，但插头怕震；
  - 走 `5V` 排针：结实，但**不能同时插电脑 USB**（两个 5V 源对打）。
    建议做一个"只供电"的 USB 线（剪掉数据线）或直接在排针上焊线；
- **防水**：座桶里一般淋不到，但仍建议装小防水盒，插头朝下。

## 5.5 不想焊？完全可以——全成品方案

**不需要画 PCB，也不需要焊贴片。** 关键是把"贴片器件"换成"带引脚的直插器件"，
然后用**接线端子 / 快速接线帽（Wago 221）**把它们拧在一起。全程可以不用烙铁。

### 5.5.1 器件替换表

| 原方案（贴片，要焊） | 换成（直插，能拧） | 说明 |
|---|---|---|
| SMBJ18A（DO-214 贴片） | **P6KE18A**（DO-15 轴向，600W） | 有个引脚，直接拧进端子；有白环那端接 +12V |
| SS34（SMA 贴片） | **1N5822**（DO-41 轴向，3A） | 同理，白环朝负载 |
| 1000µF 贴片/无引线 | **引线式电解 1000µF/25V** | 两根引脚，拧端子 |
| 保险丝座 | **带线汽车保险丝座**（片式）+ 接线帽 | 两头是裸线，拧/压都行 |
| PCB / 洞洞板 | **不需要** | 用 Wago 221 或接线端子排把节点并起来 |

> 直插件的功率/耐压都不比贴片差。P6KE18A 是 600W 系列，对付车载尖峰够用；
> 我们只走 0.2A，1N5822 的 3A 额定绰绰有余。

### 5.5.2 也就四个节点要并

```
节点①  12V 进（OBD 16 脚）      → 保险  → TVS 正端 + 防反接阳极
节点②  防反接阴极 + TVS 负端    → 模块 VIN+
节点③  模块 VIN− + OBD 4 脚     → 地
节点④  模块 5V/GND              → 开发板
```

每个节点用一颗 Wago 221（三孔或五孔）就能压三根线，免工具、可反复拆。

### 5.5.3 更省事的两种做法

**做法 A：买"带保护的"降压模块**
市面上有标注"防反接 / 防浪涌 / 带保险"的车载降压模块，买这种就只剩"串一个保险"这一步。
买之前务必看详情页是否真的写了 TVS 和反接保护，很多只是写"过流保护"（那是芯片自带的，不是防浪涌）。

**做法 B：成品 USB 输出模块 + USB 线接开发板**
如果模块自带 USB-A 输出（比如你发的那个欣薇 5A 模块），
**直接一根 USB-A 转 USB-C 线插开发板的 COM 口**，连开发板都不用接线——
只剩"12V 进模块"这一处要接，也就是两颗螺丝。

### 5.5.4 关于你发的那个模块（欣薇 9–36V 转 5.2V 5A）

| 参数 | 我们的需求 | 结论 |
|---|---|---|
| 输入 9–36V | 车上 12V（充电 13.5~14.5V，起动瞬时 9~10V） | ✅ 覆盖 |
| 输出 5.2V / 5A（25W） | 0.2A 常态、0.5A 峰值 | ✅ 余量极大，几乎不发热 |
| 同步整流、效率高 | — | ✅ 12V→5V 轻载也稳 |
| 端子/DC 头输入、USB-A 输出、背面 5V/GND 焊盘 | 免焊接线 | ✅ 最省事 |
| 保险 / TVS / 防反接 | 需要 | ❌ 板上没有，要自己串 |
| 静态电流 | 越小越好 | ❓ 未标注，**必须实测** |

三点提醒：

1. **输出 5.2V 没问题**。ESP32 开发板上的 LDO 吃得下，USB 规范也允许到 5.25V。
2. **静态电流要量**。这类模块带 USB 识别芯片，空载可能吃 5~20mA。
   我们深睡本来就只有 15~20mA，如果模块再吃 15mA，等于翻倍。
   量法：12V 输入串万用表（mA 档），不接负载，看读数。
   实测偏大就把取电点改成 ACC（熄火断电），别硬扛。
3. **USB 快充芯片不会乱升压**。它只对支持 QC 的设备协商 9V/12V；
   ESP32 开发板不会发起协商，输出一直是 5V。

## 6. 装车前必须量一次（5 分钟，能省掉一半返工）

| 量什么 | 怎么量 | 判断 |
|---|---|---|
| OBD 16 脚熄火后有没有 12V | 万用表 DC 档，16 对 4 | 有 → 常电（走方案 A 要配休眠）；没有 → 幸运，等于自带 ACC |
| ACC 保险位 | 钥匙 OFF 量一次、ON 量一次 | OFF 0V / ON 12V 才是真 ACC |
| 起动瞬间电压最低到多少 | 表笔夹住 16/4，按启动 | 低于 9V 时降压模块可能重启 |
| 整机静态电流 | 串在 5V 线上（或 USB 电流表） | 关掉模拟模式、等 60 秒入睡后量 |

## 7. 圆屏（接收端）怎么供电

圆屏现在**没有休眠逻辑**，所以它不能挂常电。三个选项：

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A. 自带电池**（推荐先这样） | 充电宝/18650 + 升压板，装在车把 | 停车可带走，防盗；不用走线 | 要记得充电 |
| **B. 车上 5V**（同一路） | 从座桶的 5V 母线拉一根到车把 | 永不断电 | 要走 1.5~2m 线；**必须从 ACC 取**，否则耗电瓶；还得防水 |
| **C. 车上 5V + 加休眠** | B + 给圆屏加"无数据 3 分钟熄屏/深睡" | 最省心 | 要改固件（半天工作量） |

先按 A 用；如果觉得每次插拔麻烦，再做 C。

## 8. 后续可以做的固件配合（按性价比排序）

1. **收发器 Rs 待机**（省 ~10mA，静态耗电减半）
   加一根 GPIO → 模块 RS 脚，深睡前拉高。硬件 1 根线，固件 5 行。
2. **圆屏休眠**：无数据 N 分钟后熄屏/深睡，触摸或收到数据唤醒。
3. **唤醒策略优化**：现在 5 分钟醒一次探总线；可以改成"ACC 上升沿唤醒"（要占一个 GPIO）。
4. **电量/电压监测**：给 12V 输入加分压电阻到 ADC，屏幕上显示电瓶电压（顺便能看出电瓶健康）。

## 9. 风险清单

- **保修**：破线（B2）可能影响保修；B1/方案 A 影响最小。
- **安全**：所有正极必须经过保险；接头必须绝缘；远离排气管和运动件。
- **防水**：踏板车座桶在雨天会进水汽，电子件装防水盒，插头朝下。
- **震动**：所有插头/接线端子必须有机械固定，不能只靠插拔力。
- **别在骑行中调试**：所有接线在熄火状态完成，上电前用万用表确认没有短路。
