三个阶段

① 现在 · 充电宝 已用

充电宝 → USB-C 插开发板 COM 口（不是另一个 USB 口）。一根线同时给电和串口。

  • 用直角 USB-C 线，减少插头受力
  • 充电宝别选"轻载自动关机"的：我们只有 0.2A，有的便宜货会误判空载断电
  • 症状：骑一会儿灯灭 / 屏上显示"发送端未连接"

② 装车 · OBD 取常电 推荐先这样

OBD 16 脚（常电）→ 保险 → 降压模块 → 开发板。不破线，30 分钟能装完。

③ 加强 · ACC 只做使能

如果经常把车停放一两周：在②上串一个继电器，用 ACC 控制通断。熄火后整机彻底断电，静态电流 0。

OBD 取电 vs ACC 取电

A. 从 OBD 16 脚取常电

怎么做：现有那根白色 16 针公头，把 16 脚（常电） 和 4 脚（地） 挑出来， 16 脚 → 保险 1A → 模块 IN+，4 脚 → 模块 IN−，输出 5V 给板子。CAN 也从这个插头出。

优点

  • 不改原车线束，保修期内最容易解释
  • OBD 座自带 7.5~10A 保险，天然多一层保护
  • 电源和 CAN 同一个插头，共地天然，只走一根线
  • 要回滚就拔插头

缺点

  • 16 脚是常电，靠固件深睡兜底，长期停放会耗电瓶
  • 插头长期插着会松动/氧化，震动大 → 必须扎带固定
  • 插着它就插不了诊断仪（要用诊断时拔掉，或买一分二）
  • 有的车型 16 脚受 ECU 控制，熄火其实没电 → 装车前量一下

B. 从 ACC 取电

三种做法（推荐度从高到低）

B1 保险盒取电器（不破线）
按车上保险片尺寸买 fuse tap，插在 ACC／点烟器／喇叭 的保险位，会多出一根正极线；负极就近搭铁。

B2 并接尾灯/牌照灯正极（破线）
刺破夹或剥皮焊接 + 热缩。震动下虚接高发，不推荐。

B3 ACC 只做信号，大电流仍走 OBD 常电（最稳）

OBD 16 ──保险──┬─────────────────> 降压 IN+
               └─ 继电器触点 30→87 ─┘

ACC ──1kΩ──> 继电器线圈 85
车身地 ─────> 继电器线圈 86

ACC 只驱动线圈（几十 mA），不给细线加负载；熄火继电器断开，整机断电。

优点

  • 熄火即断电，完全不耗电瓶（最大价值）
  • 不用操心"停放两周打不着火"

缺点

  • 要找 ACC，不同车型位置不一样
  • 起动瞬间电压跌到 9~10V，降压模块可能重启
  • 破线/加件影响保修（B1 影响最小）
  • ACC 线细，不能直接带负载（所以才要 B3 的继电器）

怎么选

OBD 常电ACC 取电
改动量极小中
破线不用B1 不用 / B2 要破
熄火耗电15~20 mA0
长期停放每天掉 6%无影响
起动压降不影响（本来在睡）可能重启
适合每周都骑经常停放

建议：先做 A（半小时、不破线），骑一两周看电瓶状态。真不行再加 B3 的继电器，而不是拆掉重来。

接线拓扑图

CAN 与地

OBD 6  (CAN-H) ─┐  双绞，<30cm
OBD 14 (CAN-L) ─┴──> SN65HVD230 CANH / CANL

OBD 5  (信号地) ───> SN65HVD230 GND
                    ↑ 与电源地只在 OBD 插头处汇合（单点接地）

为什么电源地和信号地要分开：0.2A 的电流在地线上会产生压降，抬高了 CAN 的共模电压，接收裕量变小。只在插头处汇合就没有这个问题。

那些元件到底是干什么的

车上 12V 一点都不干净：发电机调压、起动机通断、点火线圈、继电器断开，都会甩出几百伏、几微秒的尖峰。下面四件套就是为这个准备的，顺序不能换。

保险丝 · 1A 防火灾

干什么：线束一旦短路（磨破皮、进水），电流会瞬间到几十安，把线烧红甚至起火。保险丝在几十毫秒内熔断，牺牲自己保车。

不装会怎样：短路时没东西拦着，最坏是烧线束。这是唯一一个"涉及安全"的元件，不能省。

怎么选：负载 0.2A，选 1A。如果后面接了大电容，用慢熔（T）的，否则开机充电瞬间可能误熔断。

TVS · SMBJ18A 防打火尖峰

干什么：平时它像不存在（高阻，不导通）。只要电压超过约 18V，它瞬间变成导体，把尖峰的能量泄放到地，把电压钳在 ~29V 以内。

不装会怎样：降压模块输入端的 MOS 耐压通常 30~40V，一次打火脉冲就能打穿 → 模块"突然没输出了"，严重时内部短路、烧保险。这种故障没有征兆，很难查。

怎么选：SMBJ18A。18V 关断电压高于充电时的 14.5V（不会误动作），钳位 29V 低于模块耐压。单向/双向都行，直流用单向。

肖特基二极管 · SS34 防接反

干什么：只让电流单向通过。串在正极上，接反时它截止，后端一点电都拿不到，也就不会炸。

为什么用"肖特基"而不是普通二极管：压降只有 0.3~0.5V（普通硅管 0.7~1V）。我们 0.2A × 0.4V = 0.08W，可以忽略；如果用普通管，压降大、发热多，12V 跌到 11.5V 再进模块也更吃亏。

不装会怎样：接线时手一抖把正负极接反，模块和开发板一起报废。装车改线时这很常见。

大电流场合（几安培）会用 P-MOS 理想二极管，压降 0.02V，但这里没必要。

电解电容 1000µF 储能 · 防重启

干什么：储能。ESP-NOW 发射瞬间，电流会从 0.2A 跳到 0.5A，持续几十~几百微秒。而电线本身有电感（大约 1µH/米），电流不能突变，这几微秒里模块来不及供上，电压就会瞬间塌陷。

不装会怎样：电压塌陷到 ESP32 的复位阈值以下 → 莫名其妙重启。现象是"骑一会儿重启一次""数传着数着断了"，看起来像固件 bug，其实全是电的问题。线越长越容易犯。

关键：装在负载端（开发板旁边），不是装在模块输出端。要抵消的是"线"的电感，离负载越近越有效。

瓷片电容 0.1µF 滤高频

干什么：旁路高频噪声。降压模块内部以几百 kHz 开关，会产生几十 MHz 的振铃；电解电容因为自身等效电感（ESR/ESL），对这么快的信号"反应不过来"，所以并一颗小瓷片专门吃高频。

不装会怎样：开关噪声会顺着电源线跑进 ESP32 和 CAN 收发器。CAN 对噪声更敏感，可能表现为偶发坏帧、丢包——同样很难查。

怎么接：和电解并联，越靠近芯片引脚越好（几毫米）。

装车前量 4 个数（5 分钟）

量什么怎么量结论
OBD 16 脚熄火后有没有 12VDC 档，16 对 4有 → 常电（要配休眠）；没有 → 等于自带 ACC
ACC 保险位钥匙 OFF / ON 各量一次0V → 12V 才是真 ACC
起动瞬间最低电压表笔夹 16/4，按启动低于 9V 模块可能重启
整机静态电流串在 5V 线（或 USB 电流表）关掉演示模式，等 60 秒入睡后量

先量这 4 个数再下单：16 脚是不是常电，会直接改变方案选择。

圆屏（接收端）怎么供电

圆屏没有休眠逻辑，所以不能挂常电。

方案优点缺点
A. 自带电池
充电宝/18650 + 升压板		停车带走防盗；不用走线要记得充电
B. 车上 5V
从座桶 5V 母线拉一根		永不断电要走 1.5~2m 线；必须从 ACC 取否则耗电瓶；要防水

先按 A 用；觉得每次插拔麻烦，再做 C。

风险清单

保修 破线（B2）可能影响保修，B1 / OBD 取电影响最小。
安全 所有正极必须过保险；接头必须绝缘；远离排气管和运动件。
防水 座桶雨天会进水汽，电子件装防水盒，插头朝下。
震动 插头、端子必须有机械固定，不能只靠插拔力。
调试 所有接线在熄火状态完成，上电前用万用表确认没有短路。
