为什么正下方要留 120° 缺口

指针永远扫不到正下方，所以水温行可以放在那里而不被遮挡。这是整个布局的地基，改动扫角会连带改动水温位置。

3.5 水温行（文字形式）

为什么数字中心是 346 而不是 340

数字用 middle 锚点，两位「42」与三位「108」都以同一点居中——三位数会向左多占 13px。左侧必须让出这段空间，否则「108」会压到「水温」上。现在三位数时左侧仍有 5.5px 间距。

这也顺带解决了抖动：数字中心固定，位数变化时整行不会横向跳。

五、绘制顺序与“禁止出现”清单

5.1 DOM 顺序（不可乱）

外底板 → 环带 → 外倒角 → 内缘暗线 → 顶部反射弧
 → 槽底 → 槽内壁 → 槽外沿 → 橙块 → 红块
 → 刻度 → 内盘面 → 盘面白边
 → 刻度数字 → 单位小字 → 水温行
 → 指针 → 金属轴心
三条硬规则

① 凡是要画在盘面上的东西，DOM 顺序必须在盘面之后。曾把数字组放在盘面之前，整片数字被盖住，现象是“数字消失了”而不是“位置错了”。

② 指针必须在数字之后，否则数字会浮在针上面。

③ 轴心必须在指针之后——这是“贯穿感”的唯一来源：先画整根长针，再用轴盘遮住中段。

5.2 本版明确不含的元素

元素状态原因
外圈底部灰弧（±38°）已删除参考图里没有，是我凭空补的“光泽”。不要再加回来

八、改版流程（防止再改到别的东西）

  1. 先复制：gauge-ui-beta.html → gauge-ui-vN.html，在副本上改，基线文件保持不动。
  2. 只动点名的元素：增删对应 DOM 元素或改对应变量。不要重写整段 <defs>——曾因重写 defs 把 plateG / faceG 的停靠点和三组投影参数一起改掉，整体质感失真。
  3. 一次只改一处，确认没影响到别处再改下一处。
  4. 改完核对：半径单调关系（第二节）、绘制顺序（5.1）、可用色值表（第四节）。
  5. 不要补参考图里没有的元素。这是最近一次翻车的原因——加了底部弧，用户第一眼就看出来。
  6. 验收通过后另存为新的 beta，并把本表升版。
改完跑一遍校验脚本，别靠肉眼对本表

python3 docs/check-ui.py docs/gauge-ui-vN.html

脚本会检查三类：必备参数（本表第三、四节的硬性数值）、禁用元素（第五节点名的那些东西有没有被加回来）、绘制顺序与标签闭合。全部通过才输出“与 beta-1 规格一致”。

不带参数时默认校验基线：python3 docs/check-ui.py。它抓的是“数值漂移”，抓不到“观感变差”，但那正是本表存在的意义。

一句话判断标准

改完之后，如果不能逐条指着本表说明“我只改了第 X 项”，那就说明改多了，回退重来。
